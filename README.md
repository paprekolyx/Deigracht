Веб-редактор для оформления хоумбрю-материалов к D&D и другим настольным
ролевым играм: слева пишешь Markdown — справа видишь книжный разворот
в стиле официальной книги правил: пергаментный фон, две колонки, фигурные
заголовки, статблоки монстров, врезки-заметки, широкие блоки на всю страницу,
оглавление с номерами страниц, разрывы страниц — и экспорт в PDF печатью
браузера. Идеологический образец — **The Homebrewery** (naturalcrit.com,
MIT License), недоступный автору проекта; цель — тот же инструмент, но
с **первоклассной кириллицей**, без внешних CDN и с полностью открытым кодом.

**Название:** **Дейгрихт** — собственное русское название творческого проекта
владельца; **Deigracht** — транслитерация для репозитория/URL (утверждено
07.10.2026, ВЛ-01; уточнение владельца 07.10.2026: оригинальный язык
названия — русский; проверка уникальности — `docs/plan/otchet.md` §7).
**Сайт-черновик:** `https://paprekolyx.github.io/Deigracht/` (жив с волны

## Стек (факт; обоснование и ADR — `docs/plan/otchet.md` §4)

| Слой | Технология |
|---|---|
| Вёрстка | HTML5, CSS3 (дизайн-токены на CSS-переменных), vanilla JS без сборки — ADR-001 |
| Парсер | собственный: parser.js (Markdown → AST) + blocks.js (V3) + render.js (AST → DOM программно, без innerHTML — XSS-защита, SECURITY §2) |
| Пагинация | pages.js: страницы-контейнеры фиксированной геометрии (CSS columns) + JS-измерение переполнения (прототип АН-07) |
| Шрифты | 4 семейства OFL с кириллицей, 20 файлов woff2 (~470 КБ), локально: Alegreya, Cormorant Unicase, Fira Sans Condensed, Ruslan Display (ADR-002 ред. 1.1; OFL-тексты — assets/fonts/) |
| PDF | print.css + инъекция `@page`-геометрии (pdf.js), window.print() — без серверов |
| Данные | localStorage (документ + настройки); сервера и базы нет (ВЛ-04) |
| Хостинг | GitHub Pages (Deploy from a branch); репозиторий публичный; работает и с file:// (двойной клик) |
| Тесты | `python3 tests/check-repo.py` v1.8 (13 групп проверок) + `node tests/parser-smoke.js` (123 проверки: safeUrl, AST, блоки V3, `_`-границы, TOC-префиксы, 30 fuzz-кейсов, регресс эталона) + `node tests/render-smoke.js` (56 проверок рендера на DOM-заглушке, с v0.4.1 — АН-27) — все exit 0 |

Принцип проекта: **ноль внешних CDN и ноль рантайм-зависимостей** —
всё вендорится или пишем сами.

## Инструкции

- **Запуск локально:** открыть `index.html` двойным кликом (file://) —
  редактор полностью работоспособен без сервера.
- **Публикация:** `docs/setup/setup-repo-pages.md` (Pages живёт с волны
  v0.1.2 — `.nojekyll` обязателен, грабля №14); после публикации обновлять
  сайт с **Ctrl + F5**.
- **Проверки:** `python3 tests/check-repo.py`, `node tests/parser-smoke.js`
  и `node tests/render-smoke.js` из корня репозитория — все должны давать
  exit 0 (регламент §8.1).
- **`docs/reglament.md`** — правила ведения проекта (ред. 1.8; приложение
  §11 — префиксы документов).
- **`docs/reestr.md`** — реестр документации (ред. 4.7).
- **`docs/plan/plan-razrabotki.md`** — план волн v0.0.1 → v1.0.0, DoD,
  трекер АН (ред. 1.9).
- **`docs/plan/otchet.md`** — анализ источников, архитектура, ADR-001…004,
  проверка названия Deigracht, риски (ред. 1.7).
- **`docs/plan/voprosy-vladeltsu.md`** — решения владельца (ред. 2.4; открыты
  ВЛ-12 — серверная часть v1.0.0, ВЛ-20/21/22 — не блокируют, В-4 —
  подтверждение приёмки v0.4.0).
- **`help.html`** — справка: живой справочник синтаксиса (кнопка
  «Справка» в шапке редактора) + памятка о правах.
- **`docs/update/update-v041.md`** — инструкция текущей волны; предыдущие —
  update-v001…v040.md.

## Правила ведения проекта (кратко; полностью — `docs/reglament.md`)

- **Управление:** ведущий аналитик = владелец (07.10.2026) — решения
  фиксируются датой и кодом (ВЛ/АН) без отдельных согласований.
- **Волна ≈ один MINOR** (SemVer): 0.0.x — подготовка, 0.x — черновик,
  1.0.0 — стабильный релиз (статика, без сервера — ВЛ-04).
- **Точки синхронизации версии:** SITE_VERSION (config.js) = шапки
  README/LICENSE/SECURITY (сверяет check-repo).
- **Каждая волна = новый файл** `docs/update/update-vXXXX.md`; приёмка —
  `docs/priemka/`, ревью — `docs/review/`; **exit 0 обоих тестов — индикатор
  качества волны**.
- **Коммит** — версия пакета («0.1.0-draft») или ссылка на задачу
  («(АН-03 п.2, ВЛ-02)»).
- **Честные границы**: упрощения черновика перечислены явно (SECURITY.md §3,
  техпаспорт §10).
