Веб-редактор для оформления хоумбрю-материалов к D&D и другим настольным
ролевым играм: слева пишешь Markdown — справа видишь книжный разворот
в стиле официальной книги правил: пергаментный фон, две колонки, фигурные
заголовки, статблоки монстров, врезки-заметки, широкие блоки на всю страницу,
оглавление с номерами страниц, разрывы страниц — и экспорт в PDF печатью
браузера. Идеологический образец — **The Homebrewery** (naturalcrit.com,
MIT License), недоступный автору проекта; цель — тот же инструмент, но
с **первоклассной кириллицей** (в оригинале книжные шрифты не содержат
кириллицы и русский текст проваливается в Times New Roman), без внешних CDN
и с полностью открытым кодом.

**Название:** Deigracht — собственное название творческого проекта владельца
(утверждено 07.10.2026); проверка на совпадения выполнена — конфликтов
не найдено (`docs/plan/otchet.md` §7).
**Сайт-черновик:** ещё не опубликован — появится на `https://paprekolyx.github.io/Deigracht/` с волны v0.1.0
**По работе проекта писать:** Albert23NO@ya.ru — ведущий аналитик проекта

## Что будет у сайта (ядро v0.1.0–v0.3.0 — приоритет №0; полный состав волн — `docs/plan/plan-razrabotki.md`)

| Возможность | Состав |
|---|---|
| Редактор с живым предпросмотром | две панели: Markdown-исходник → книжный разворот; прокрутка и правки без перезагрузки |
| Синтаксис Homebrewery V3 | ```` ```metadata ````-блок (title/description/tags/renderer/theme), `{{wide}}`, `{{note}}`, `{{descriptive}}`, `{{monster}}`, `{{toc}}`, `{{column-count}}`, `{{pageNumber}}`, `\page`, `___`-статблоки, таблицы; **изображения** (`![]()`, `{{imageMask*}}`) — **с v1.0.0** (fp №18, решение владельца 07.10.2026): в черновике вместо них плейсхолдеры |
| Тема «книга правил» (5ePHB-стиль) | пергамент, колонки, цветные заголовки, буквицы, рамки врезок, статблоки с красными линейками; **шрифты — готического склада, OFL с кириллицей, локально (woff2)** — кандидаты в `docs/plan/otchet.md` ADR-002 |
| Экспорт в PDF | print-раскладка (`@page`), **переключатель A4/Letter** (ВЛ-07; дефолт Letter — геометрия эталона), колонтитулы и номера страниц, печать браузером без серверов; модальное окно печати — с блокировкой фонового скролла (требование владельца 07.10.2026) |
| Импорт существующих документов | вставил/загрузил `.md` из Homebrewery — получил тот же документ; **критерий приёмки ядра: документ владельца «Всемирная история» (65 стр., ~180 тыс. знаков, 211 `{{`-блоков, 49 `\page`, 3 монстр-блока, 577 строк таблиц) рендерится и печатается корректно** (9 картинок эталона — плейсхолдеры до v1.0.0) |
| Хранение и экспорт файлов | черновик без сервера: с v0.1.0 — автосохранение текущего документа и экспорт/импорт `.md` (storage-минимум); полная библиотека документов — fp №6 (приоритет №7, v0.9.0); передача документов — PDF, `.md` и **самодостаточный `.html`** (fp №7б); серверный шаринг не планируется (ВЛ-04) |

Полный бэклог (справка и сниппеты, авто-TOC, конструктор статблоков, история
версий, свои темы, библиотека, тёмный UI, мобильная адаптация, i18n) —
нумерованные fp-карты №1–№19 в **`docs/feature-proposals.md`** (ред. 2.0);
порядок разработки **утверждён владельцем 07.10.2026** (ВЛ-02 закрыт);

## Стек (план; обоснование и ADR — `docs/plan/otchet.md` §4)

| Слой | Технология |
|---|---|
| Вёрстка | HTML5, CSS3 (дизайн-токены на CSS-переменных), vanilla JS (ES6+) без сборки |
| Парсер | собственный Markdown-парсер + надстройка блоков V3 (без внешних зависимостей и CDN) |
| Шрифты | OFL-шрифты готического склада с кириллицей, локально woff2 (ADR-002; проверка на эталоне — АН-03) |
| PDF | print-CSS + `window.print()`, форматы A4/Letter — без серверной генерации |
| Данные | сервера и базы нет (ВЛ-04): документы в localStorage/IndexedDB браузера |
| Хостинг | GitHub Pages (Deploy from a branch); репозиторий публичный |

Принцип проекта: **ноль внешних CDN** — всё вендорим или пишем сами.

## Правила ведения проекта (кратко; полностью — `docs/reglament.md`)

- **Управление:** ведущий аналитик = владелец проекта (решение 07.10.2026) —
  согласования решений документируются датой и кодом (ВЛ/АН) без отдельных
  процедур утверждения.
- **Волна ≈ один MINOR** (SemVer): у волны есть состав работ, DoD и оценка
  в РД; версия `0.0.x` — подготовка (документальные волны), `0.x` — черновик,
  `1.0.0` — стабильный релиз (статика, без сервера — ВЛ-04).
- **Документы живут в репозитории** и синхронны версии: шапки README /
  LICENSE / SECURITY несут «Версия документа: 0.X.Y-draft · ДАТА».
- **Каждая волна = новый файл** `docs/update/update-vXXXX.md` (созданные
  не редактируются); приёмка — `docs/priemka/`, ревью — `docs/review/`.
- **Коммит** — либо версия пакета («0.0.2-draft»), либо ссылка на задачу
  («(АН-03 п.2, ВЛ-02)»).
- **Честные границы**: упрощения черновика перечислены явно (SECURITY.md,
  README), SECURITY описывает фактическое состояние, а не намерения.
