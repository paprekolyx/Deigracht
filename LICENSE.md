# Лицензия Grimoire (черновой проект)

**Версия документа:** 0.0.1-draft · 07.10.2026
**Правообладатель:** [владелец проекта, ФИО/статус — подставляется в волне M0
боевого этапа; до этого — рабочий контакт аналитика].
**Контакт для связи:** Albert23NO@ya.ru — ведущий аналитик проекта.

Проект — некоммерческий веб-редактор для оформления любительских (homebrew)
материалов к настольным ролевым играм. Проект состоит из кода и творческого
содержимого разной природы (темы оформления, текстуры, типографика, тексты
справки), поэтому лицензия состоит из частей. Схема унаследована из проекта
Sisku (решение владельца 07.10.2026, вопрос ВЛ-05 опросника).

## Часть 3. Отдельные оговорки

1. **Название Grimoire — заглушка.** Оно будет заменено до боевого запуска
   (ВЛ-01) и не передаётся по настоящей лицензии как товарное обозначение.
2. **Wizards of the Coast.** Проект не аффилирован с Wizards of the Coast LLC
   и не одобрен ею. «Dungeons & Dragons», «D&D» и связанные обозначения —
   товарные знаки Wizards of the Coast LLC. Проект следует Fan Content Policy
   WotC: предоставляется бесплатно, без извлечения прибыли, «как есть»,
   без претензии на официальность. Стилизация тем «под книгу правил» —
   творческая интерпретация, не копия защищённого оформления официальных книг.
3. **Содержимое SRD.** Если в будущих волнах в проект включаются фрагменты
   System Reference Document 5.1, они распространяются под Creative Commons
   Attribution 4.0 International (CC-BY-4.0) с обязательным указанием
   правообладателя — Wizards of the Coast LLC; перечень включённых фрагментов
   и атрибуция публикуются отдельно.
4. **Шрифты и сторонние компоненты** используются по собственным лицензиям,
   которые не изменяются настоящим документом: шрифты — только SIL Open Font
   License 1.1 (или равнозначно свободные) с кириллицей; перечень с версиями
   ведётся в `docs/tehpasport.md` §15 и обновляется каждой волной, добавившей
   компонент. The Homebrewery (naturalcrit/homebrewery, MIT License)
   использовался только как образец синтаксиса и UX — код не копировался.
5. **Документы пользователей.** Права на документы, созданные в редакторе,
   принадлежат создавшим их пользователям. Сервис не претендует на эти права,
   не использует содержимое документов в собственных целях; в черновике
   документы хранятся только в браузере пользователя (см. SECURITY.md).
6. **Персональные данные.** Репозиторий не содержит персональных данных;
   черновик не собирает их (нет сервера, аналитики и аккаунтов — границы
   описаны в SECURITY.md).
7. **Боевая версия проекта** (если появится: серверное хранение, шаринг,
   аккаунты) будет распространяться отдельно и на иных условиях; условия
   настоящего документа продолжают действовать для этого репозитория
   и его истории.

## Как это выглядит на практике

| Что вы хотите сделать | Можно ли |
|---|---|
| Изучить код, сделать учебный проект по мотивам | Да (часть 1) |
| Взять парсер/рендерер блоков V3 в свой инструмент | Да, с указанием источника (часть 1) |
| Использовать тему-«пергамент» и текстуры в своём коммерческом продукте | Нет (части 2 и 3) |
| Создавать в редакторе свои книги и продавать/публиковать их | Да — это ваши документы (часть 3 п.5); сам редактор при этом бесплатен (Fan Content Policy) |
| Продавать что-либо под обозначением Grimoire | Нет (часть 3) |
