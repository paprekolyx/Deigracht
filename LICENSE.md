# Лицензия Deigracht (черновой проект)

**Версия документа:** 0.1.1-draft · 07.10.2026
**Правообладатель:** **paprekolyx** (псевдоним). Публикация ФИО и статуса
не требуется и не выполняется — решение владельца (ВЛ-05) от 07.10.2026:
достаточно контакта для связи; законодательство допускает указание
правообладателя-псевдонима (ст. 1265 ГК РФ — произведение, обнародованное
без указания имени; условия MIT не требуют раскрытия личности).
**Контакт для связи:** Albert23NO@ya.ru — ведущий аналитик проекта.

Проект — некоммерческий веб-редактор для оформления любительских (homebrew)
материалов к настольным ролевым играм; бесплатный всегда, монетизация
не планируется (ЮР-01, 07.10.2026). Проект состоит из кода и творческого
содержимого разной природы (темы оформления, текстуры, типографика, тексты
справки), поэтому лицензия состоит из частей. Схема (код / содержимое /
оговорки) утверждена решением владельца 07.10.2026.

## Как это выглядит на практике

| Что вы хотите сделать | Можно ли |
|---|---|
| Изучить код, сделать учебный проект по мотивам | Да (часть 1) |
| Взять парсер/рендерер блоков V3 в свой инструмент | Да, с указанием источника (часть 1) |
| Использовать тему-«пергамент» и текстуры в своём коммерческом продукте | Нет (части 2 и 3) |
| Создавать в редакторе свои книги и продавать/публиковать их | Да — это ваши документы (часть 3 п.5); сам редактор при этом бесплатен (Fan Content Policy) |
| Продавать что-либо под обозначением Deigracht | Нет (часть 3) |
