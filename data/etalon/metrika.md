# Метрики эталона (регресс-приёмка)

**Статус:** замороженные метрики эталонного документа (регламент §8.4 —
эталон прогоняется каждой кодовой волной). Источник фактов — прогон
`tests/parser-smoke.js` (Node) 07.10.2026, волна v0.1.1; изменения метрик
допускаются только вместе с изменением эталона или фиксом парсера
(с объяснением в update-инструкции волны). **Перепроверка v0.4.1
(07.10.2026):** метрики §2 не изменились — ядро парсера волнами v0.4.x
не тронуто (подтверждено recheck-ревью rev040 §5 и прогоном parser-smoke
123 проверки); правка метрики страниц §3 — см. строки v0.3.1/v0.4.1
(журнал rev040-recheck, записи 4 и 8).
**Файл эталона:** `etalon-sint.md` — **синтетическая структурная копия**
эталонного документа владельца «Всемирная история» (Homebrewery V3, 5ePHB):
блок-каркас, счётчики и синтаксические конструкции воспроизведены точно,
текст — генерированный наполнитель («ааа ббб ввв…»). **Решение владельца
07.10.2026: авторский творческий текст в публичном репозитории не
публикуется** (грабля №12 регламента). Приёмка визуального сходства с книгой
и PDF-оригиналом (65 страниц, Letter) выполняется владельцем **локально**
на своём документе («Открыть .md» в редакторе) — он в репозиторий не
загружается.

## 4. Как проверять

```
node tests/parser-smoke.js      # метрики §2 (exit 0 = зелёный)
python3 tests/check-repo.py     # целостность репозитория (exit 0)
```
Браузерная проверка — чек-лист приёмки в update-инструкции текущей волны:
открыть редактор → «Открыть .md» → выбрать эталон → сверить разворот;
`Печать / PDF` → Letter (число страниц — по §3 текущей волны).
