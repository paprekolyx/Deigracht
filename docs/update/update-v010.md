# Инструкция обновления v0.1.0-draft (первая кодовая волна)

**Дата:** 07.10.2026 · **Волна:** v0.1.0-draft · **Тип:** кодовая
(редактор реализован; публикация + включение Pages — за владельцем, АН-15).
Формат разделов — регламент §7.2.

---

## 1. Что изменилось

**Задача волны** (план §1, волна 1): статический каркас + ядро рендера —
fp №1 (редактор), fp №3 (тема книги), fp №4 (PDF), fp №2 часть 1
(Markdown-ядро), storage-минимум, тесты, эталон. Гейты АН-03/05/07/09
закрыты в составе волны.

1. **Сайт (впервые):** `index.html` — редактор: две панели с перетаскиваемой
   границей (ширина сохраняется), debounce-рендер 300 мс, синхронная
   прокрутка, счётчики страниц/слов/знаков, горячие клавиши Ctrl+S/Ctrl+P,
   «Открыть .md» (клик и drag&drop), «Сохранить .md», демо-документ при
   первом запуске; `404.html` для Pages.
2. **Конвейер рендера (собственный, ноль зависимостей):** parser.js
   (Markdown → AST: заголовки, абзацы, списки вложенные, таблицы с
   выравниванием и `\|`, цитаты, код-блоки, линейки, ссылки, `\page`,
   ```` ```metadata ````; изображения — плейсхолдеры до v1.0.0) → blocks.js
   (блоки `{{…}}` — помеченные заглушки до v0.2.0, однострочные
   `{{pageNumber,auto}}` — распознаны) → render.js (AST → DOM программно,
   без innerHTML — XSS-защита; safeUrl-whitelist ссылок) → pages.js
   (пагинация измерением: жадный батч 8 блоков + откат, `\page`, нумерация,
   колонтитулы, честная отметка блока крупнее страницы).
3. **Тема книги (fp №3):** tokens.css (дизайн-токены) + theme-book.css —
   пергамент (parchment.svg, собственная CC0-текстура), две колонки,
   капители-заголовки, буквицы после h1, линейки, таблицы в стиле книги
   правил, врезки-заглушки; **шрифты — АН-03 закрыта:** 4 семейства OFL
   с кириллицей (Alegreya, Cormorant Unicase, Fira Sans Condensed,
   Ruslan Display), 20 файлов woff2 (cyrillic+latin, ~470 КБ), 4 OFL-текста,
   manifest.json, fonts.css (сгенерирован из манифеста).
4. **Печать/PDF (fp №4):** модалка печати **с блокировкой фонового скролла**
   (требование владельца 07.10.2026 — html.modal-lock + компенсация
   скроллбара), переключатель **A4/Letter** (дефолт Letter — ВЛ-07,
   ADR-003 ред. 1.1), инъекция `@page`-геометрии, print.css (1 экранная
   страница = 1 печатная, UI скрыт), настройка формата сохраняется.
5. **Storage-минимум:** автосохранение документа в localStorage (1 с
   debounce), экспорт/импорт `.md`, честное предупреждение при переполнении
   квоты; полная библиотека — fp №6 (v0.9.0).
6. **Безопасность (SECURITY §2 — теперь факт):** CSP мета-тег
   (`default-src 'self'; script-src 'self'; style-src 'self' 'unsafe-inline';
   img-src 'self' data:; …`); safeUrl (10 векторов в тесте); ноль CDN;
   favicon — собственная иконка книги (ВЛ-03).
7. **Тесты (АН-01 закрыта):** `tests/check-repo.py` v1.0 — 12 групп
   проверок целостности (REQUIRED, версии, хронология, MD-гигиена H1/CJK,
   внешние упоминания, локальность ресурсов, пары JS↔HTML, баланс тегов,
   секреты, шрифты, эталон); `tests/parser-smoke.js` (Node ≥16, без
   зависимостей) — 51 проверка: safeUrl-вектора, AST синтетики,
   XSS-инертность, frozen-метрики эталона. **Оба exit 0 локально
   (07.10.2026).** В ходе тестов найдены и исправлены 2 бага парсера
   (слияние разнотипных списков; однострочные `{{…}}`-блоки).
8. **Эталон (АН-02 закрыта):** `data/etalon/vsemirnaya-istoriya.md` (копия
   документа владельца, 311 409 байт) + `metrika.md` — frozen-метрики
   (49 `\page`, 491 заголовок, 77 таблиц/577 pipe-строк, 123 блока `{{…}}`
   по модификаторам, 9 инлайн-картинок, 0 незакрытых блоков) и ожидаемое
   поведение по волнам v0.1.0/v0.2.0/v1.0.0.
9. **Документы синхронизированы:** README/SECURITY/LICENSE — 0.1.0-draft;
   техпаспорт — фактическое состояние (§4–§5 состав и модули, §9 первые
   эксплуатационные заметки: парсер ~50 мс на эталоне, пагинация — точка
   роста, шрифты swap; §10 — 10 ограничений; §13 — реестр компонентов);
   реестр ред. 4.0 (код, инструменты §7.1–§7.4); план ред. 1.3 (статусы
   волн и АН); fp ред. 2.1 (№1/№3/№4 — «Уже реализовано», №2 ч.1);
   регламент ред. 1.3–1.4 (§4.5 — работа в основном дереве без package-папок,
   решение владельца 07.10.2026; грабля №11).

## 7. Урок для регламента

- **Грабля №11 (новая, внесена в регламент ред. 1.4):** веб-загрузка GitHub
  молча теряет часть файлов пакета — в волнах v0.0.2/v0.0.3 не доехали
  `.gitignore` и два `.keep` (dot-файлы и пустые файлы); обнаружено сверкой
  дерева репозитория с локальным составом (git blob sha). Мера: сверка
  дерева — обязательный пункт чек-листа каждой волны (§4); dot-файлы
  создавать через «Create new file»; с v0.1.0 состав REQUIRED в check-repo
  делает потерю видимой на следующей волне.
- **Наблюдение:** смоук-тест парсера на эталоне (Node, без браузера) окупился
  в той же волне — пойманы 2 реальных бага до публикации (слияние
  разнотипных списков; однострочные `{{…}}`-блоки эталона — 51 шт.
  `{{pageNumber,auto}}`). Практика закреплена: каждый новый модуль с чистой
  логикой получает Node-смоук в tests/ (реестр §7.2).
