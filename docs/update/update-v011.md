## 1. Что изменилось

**Задача волны:** три поручения владельца (сообщение 07.10.2026):
(1) авторский творческий документ не публикуется в репозитории — заменить
синтетическим текстом с теми же блоками; (2) сверка GitHub после загрузки
v0.1.0; (3) диагностика «сайт не собирается» при включённом Pages.

1. **Синтетический эталон (решение владельца → грабля №12 регламента):**
   вместо копии документа «Всемирная история» в `data/etalon/` опубликован
   **`etalon-sint.md`** — структурная копия блок-каркаса, сгенерированная
   детерминированно (seed 42): все frozen-метрики идентичны оригиналу
   (49 `\page`; заголовки 2/26/82/144/98/139; 77 таблиц — 423+77+77 =
   577 pipe-строк; 123 блока `{{…}}`: 51 `{{pageNumber,auto}}`, 30 note,
   17 column-count:2, 9 wide, 9 imageMask (Center 2, Edge6 4, Edge7 1,
   Edge2 1, Corner9 1), 3 descriptive, 3 monster (с 3 `___` и h4 внутри),
   1 toc,wide; 9 инлайн-картинок с атрибутом `{width:100%}` — как в
   оригинале; 0 незакрытых блоков), текст — наполнитель «ааа ббб ввв…»
   (178 632 знака — близко к оригиналу 180 513: замер производительности
   сопоставим). **parser-smoke на новом эталоне: 51/51, exit 0.**
   Копия оригинала удалена из локального дерева; на GitHub не загружалась
   (data/ не доехал в v0.1.0 — к лучшему). `metrika.md` переписана: факты
   синтетического файла, frozen-метрики (§2), приёмка v0.2.0/v1.0.0 —
   визуальная сверка «как книга» выполняется владельцем **локально** на его
   документе.
2. **Сверка GitHub после v0.1.0 (АН-15 — частично):** дерево 63 файла;
   index.html в корне ✓; не доехали: data/etalon/* (заменены этой волной),
   содержимое `.gitignore` (создан пустым — 1 байт); артефакты веб-загрузки
   (грабля №13): ведущий `\r\n` у 7 файлов (index.html, 404.html, 5 CSS —
   безвредно для браузера), `.keep` по 1 байту (безвредно). Отклонения
   зафиксированы в §6 — байт-в-байт идентичность не требуется.
3. **Диагностика Pages:** `has_pages: true` (Pages включён), но сайт и
   Pages API отдают 404 → сборка не завершилась/не стартовала или неверна
   папка источника. Чек-лист диагностики — **setup-repo-pages шаг 3б**
   (ред. 1.2): Branch = main + **/ (root)** (не /docs!) → Save (пересохр.);
   плашка «Your site is live at …»; Actions → «pages build and deployment»;
   подтверждён ли e-mail аккаунта; Ctrl+F5; index.html в корне.
4. **Синтаксическая находка (внесена в fp №18 п.6 и otchet §1.4):**
   изображения в оригинале имеют атрибуты `{width:100%}`/`{height:110%}`
   (Homebrewery V3) — без их поддержки картинки встанут не по макету;
   учтено в объёме v1.0.0.
5. **Регламент ред. 1.5:** грабля №12 (авторский контент не публикуется
   без явного решения; тестовые данные — синтетические реплики с
   сохранением метрик) и №13 (артефакты веб-загрузки: пустой .gitignore,
   ведущий CRLF, .keep с переводом строки; сверка дерева — по содержимому,
   известные отклонения — списком в update §6); §8.4 — регресс-эталон
   синтетический.
6. Точки версии подняты до **0.1.1-draft** (config.js SITE_VERSION, шапки
   README/SECURITY/LICENSE, таблица версий README — 5 строк).

## 7. Урок для регламента

- **Грабля №12 (новая, внесена в регламент ред. 1.5):** тестовые данные
  волны v0.1.0 содержали авторский творческий документ владельца — публикация
  в открытом репозитории не согласовывалась явно. Мера: контентное размещение
  проверяется при подготовке пакета (что публикуем?); тестовые данные —
  синтетические реплики с сохранением метрик; авторские материалы — только
  локально (приёмка на стороне владельца). Сработало штатно: data/ не доехал
  до GitHub в v0.1.0, замена выполнена до публикации.
- **Грабля №13 (новая):** веб-загрузка/веб-создание файлов GitHub даёт
  артефакты: пустой `.gitignore` при ручном создании, ведущий `\r\n`
  у загруженных текстовых файлов, `.keep` с переводом строки. Мера: сверка
  дерева по содержимому (git blob sha), а не по именам; список известных
  безвредных отклонений — в update §6; dot-файлы править веб-редактором.
- **Наблюдение:** диагностика Pages должна жить в setup-инструкции, а не
  в чате — добавлен шаг 3б (setup ред. 1.2).
