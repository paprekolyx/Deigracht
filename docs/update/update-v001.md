## 4. Публикация и проверка

1. Создать репозиторий и загрузить пакет — пошагово
   `docs/setup/setup-repo-pages.md` (веб-интерфейс или git);
2. коммит(ы) с сообщением: **`0.0.1-draft`** (регламент §4.2);
3. чек-лист приёмки:
   - [ ] все 13 файлов + 3 .keep на месте (итого 16), пути совпадают с §2;
   - [ ] ветка main, репозиторий public;
   - [ ] README открывается на главной репозитория без битой разметки
         (таблицы, дерево структуры);
   - [ ] LICENSE отображается GitHub'ом как лицензионный файл
         (определяется MIT-блок части 1);
   - [ ] SECURITY.md виден во вкладке Security репозитория;
   - [ ] Pages НЕ включён (Settings → Pages → None);
   - [ ] в репозитории нет лишних файлов (черновики drafts/, локальные
         заметки — не загружены; .gitignore на месте).

## 5. Финальная проверка
