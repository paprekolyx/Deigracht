# Инструкция обновления v0.2.0-draft (волна синтаксиса V3)

**Дата:** 07.10.2026 · **Волна:** v0.2.0-draft · **Тип:** кодовая
(оформление блоков V3 + дробление oversized-блоков).
Формат разделов — регламент §7.2.

---

## 1. Что изменилось

**Задача волны** (план §1, волна 2; fp №2 ч.2): блоки Homebrewery V3
перестают быть заглушками и получают книжное оформление; oversized-блоки
дробятся между страницами вместо красных флагов.

1. **blocks.js — полное оформление блоков:**
   - `{{wide}}` — во всю ширину разворота (column-span: all);
   - `{{note}}` — врезка-рамка на светлом пергаменте;
   - `{{descriptive}}` — флавор-блок с верхним/нижним линейками, курсив;
   - `{{monster}}` — статблок-плашка: двойные линейки сверху/снизу,
     `####`-имя капителью, `___` — двойная линейка, черты/таблицы/списки
     в компактной типографике;
   - `{{toc}}` — оглавление: точечные лидеры, номер страницы справа,
     клик по `#pN` скроллит к соответствующей странице превью (editor.js);
     формат подписей источника `[{{ Название}}{{ N}}](#pN)` распознаётся;
   - `{{column-count:N}}` — директива: закрывает текущую страницу и открывает
     новую с N колонками (1–4; некорректное N → 2);
   - `{{pageNumber,…}}` — скрытый маркер совместимости: нумерация живёт
     в колонтитуле каждой страницы (pages.js);
   - `{{imageMask*}}` — плейсхолдер с именем модификатора (до v1.0.0, fp №18);
   - неизвестный модификатор — видимая плашка «не поддерживается»
     (честное правило совместимости, otchet §1.4).
2. **pages.js — дробление oversized-блоков** (DoD волны 2): блок, не влезающий
   в пустую страницу, разрезается бинарным поиском по измерению на атомарных
   единицах: слова абзаца/цитаты (с сохранением инлайн-форматирования),
   `li` списков, строки `tbody` таблиц **с повтором шапки thead в обеих
   частях**, дочерние элементы контейнеров (wide/note/monster/…);
   неразрезаемое (h1–h6, hr, плейсхолдеры) — прежняя честная отметка
   переполнения. Хвост разрезанного блока уходит на следующую страницу
   (рекурсивно, если тоже не влезает).
3. **theme-book.css** — стили всех блоков V3 + классы страниц
   `.page--cols-1/3/4`; **editor.js** — навигация по якорям `#pN`;
   render.js — вызов `DG.blocks.render` вместо заглушки.
4. **Тесты:** parser-smoke расширен до **89 проверок**: AST блоков V3
   (порядок модификаторов, закрытость, вложенные h4/___/картинки) +
   **fuzz-секция 30 кейсов** (незакрытые fence/`{{`, обрезанные ссылки и
   картинки, управляющие/нулевые символы, `<script>`/`onerror`, гигантские
   строки и блоки, вложенные `{{`, `javascript:`) — падений нет, исполняемых
   узлов нет. Интеграция render+blocks+pages на DOM-заглушке — зелёная
   (эталон: 1 488 элементов, конвейер 245 мс без layout).
5. **Расхождения семантик V3 зафиксированы** (otchet §1.4 ред. 1.4,
   техпаспорт §10 п.11): column-count — со следующей страницы; pageNumber —
   в колонтитуле; якоря `#pN` — экранные страницы превью (не PDF).
6. **Документы синхронизированы:** версии 0.2.0-draft (config/README/
   SECURITY/LICENSE); fp ред. 2.3 (№2 → «Уже реализовано», исходный текст
   карты сохранён как №2-old); план ред. 1.6 (волна 2 — пакет готов; АН-19
   закрыта — сайт жив с .nojekyll; АН-20 — фиксация числа страниц эталона
   при приёмке); техпаспорт 0.2.0 (§5 модули, §9 заметка о замере дробления,
   §10 п.11 расхождения); реестр ред. 4.3 (+решение владельца по data/.keep —
   вне структуры); otchet ред. 1.4.
7. **data/.keep:** задание на удаление снято — служебный файл оставлен
   владельцем косметически (решение 07.10.2026), в структуре и сверках
   дерева не учитывается.
