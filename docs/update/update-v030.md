# Инструкция обновления v0.3.0-draft (справка, сниппеты, экспорт .html)

**Дата:** 07.10.2026 · **Волна:** v0.3.0-draft · **Тип:** кодовая
(fp №10 — приоритет №1 владельца; fp №7б — решение аналитика).
Формат разделов — регламент §7.2.

---

## 1. Что изменилось

**Задача волны** (план §1, волна 3): справка и сниппеты (fp №10) + экспорт
самодостаточного .html (fp №7б — основной способ передачи документов
без сервера, логика ВЛ-04).

1. **`help.html` — живой справочник синтаксиса:** встроенный демо-исходник
   рендерится тем же конвейером (parser → render → pages), поэтому каждый
   пример показан своим книжным оформлением: Markdown-основы, таблицы,
   цитаты, `\page`, печать, все блоки V3 (`note`/`descriptive`/`wide`/
   `column-count`/`monster` со статблоком по образцу SRD/`toc` с лидерами/
   `pageNumber`), плашка неизвестного модификатора, статус изображений
   (плейсхолдеры до v1.0.0).
2. **Юридическая памятка (ЮР-02/ЮР-03)** — блок над справкой: ваши
   документы — ваши (LICENSE ч.3 п.5); ПДн в документах — ответственность
   пользователя; **Fan Content Policy WotC** — рекомендуемая плашка для
   документов шаблоном («[Название] is unofficial Fan Content permitted
   under the Fan Content Policy…»); **SRD 5.1 (CC-BY-4.0)** — шаблон
   атрибуции для фрагментов SRD; лицензии шрифтов/оформления (OFL/CC0,
   ничего из книг WotC не копируется — ВЛ-11).
3. **Меню «Вставить» (сниппеты, fp №10):** 10 заготовок — статблок
   `{{monster}}` (кость/хиты/таблица характеристик/черта/действия — по
   образцу SRD), `{{note}}`, `{{descriptive}}`, `{{wide}}`, `{{toc}}`,
   таблица, `\page`, `{{column-count:1}}`, заголовок, цитата; вставка
   в позицию курсора с заменой выделения и автопереносом; меню закрывается
   по клику вне и по вставке.
4. **«Экспорт HTML» (fp №7б):** один самодостаточный `.html` — встроенные
   стили (tokens/theme-book/print) + шрифты woff2→data:URI + снапшот
   разворота + `@page` текущего формата (Letter/A4); открывается двойным
   кликом без интернета, печатается в PDF 1:1. Сборка читает css/шрифты
   через fetch: работает с https (Pages) и локального сервера; из file:// —
   честное сообщение с подсказкой `python3 -m http.server` (техпаспорт
   §10 п.12). Имя файла — из metadata title.
5. **Тулбар редактора:** кнопки «Вставить ▾», «Экспорт HTML», ссылка
   «Справка»; CSP не менялся (fetch свой — `default-src 'self'`).
6. **Тесты/контроль:** check-repo v1.5 — REQUIRED пополнен (help.html,
   snippets.js, export.js, help.js, update-v030), пары JS↔HTML считаются
   по index/404/help; parser-smoke — 89 проверок (без изменений: парсер
   волны не тронут); регресс эталона зелёный.
7. **Документы:** версии 0.3.0-draft; fp ред. 2.4 (№10 и №7б → «Уже
   реализовано»); план ред. 1.7 (волна 3 — пакет готов; АН-08 закрыта,
   АН-21 в работе, АН-22 открыта); техпаспорт 0.3.0 (§4–§5, §10 п.12);
   реестр ред. 4.4.
