1. Открыть сайт, Ctrl+F5 (кэш!), убедиться: шапка вкладки — «Дейгрихт
   (Deigracht) — …», чип версии — 0.3.1-draft.
2. **Печать (главное):** загрузить `data/etalon/etalon-sint.md` (Пример →
   файл), Печать/PDF → в предпросмотре браузера **нет пустой первой
   страницы** (сразу книжная страница 1); записать число страниц Letter.
3. Сообщение владельцем аналитику: число страниц Letter → заморозка
   в metrika.md §3 (АН-20).
4. Проверить title help.html («Справка · Дейгрихт (Deigracht)»).
