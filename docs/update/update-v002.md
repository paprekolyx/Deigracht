# Инструкция обновления v0.0.2-draft (волна решений владельца)

**Дата:** 07.10.2026 · **Волна:** v0.0.2-draft · **Тип:** документационная

## 1. Что изменилось

**Задача волны:** обработка ответов владельца (сообщение от 07.10.2026 —
зафиксированы в `docs/plan/voprosy-vladeltsu.md` ред. 2.0) + четыре
отдельных поручения волны. Управление: ведущий аналитик = владелец
(решение 07.10.2026, регламент §0) — согласования не требуются.

1. **Очистка документов от ссылок на сторонние проекты** (поручение 1):
   упоминания стороннего проекта удалены из всех документов
   репозитория; единственное исключение — `docs/plan/otchet.md` (анализ
   источников — его содержание; имя проекта в прочих документах не
   приводится — иначе grep-проверка §5 обнаруживает их сами, грабля №8
   в действии). Правило закреплено: регламент §3.5, грабля №8, проверка
   в update §5 и в check-repo с v0.1.0 (АН-01). `update-v001.md`
   перенёс однократную документированную правку (исключение [Н] —
   регламент §7.3): состав и факты волны v0.0.1 не изменялись.
2. **Название — Deigracht** (поручение 2 + ВЛ-01): переименование во всех
   документах; проверка уникальности выполнена (АН-11 закрыта — веб-поиск:
   единственное совпадение, артефакт OCR голландской газеты 1909 г.;
   GitHub repos/users/issues — 0; результат — otchet §7, риск R8).
   Переименование репозитория — шаг загрузки (§4).
3. **Рамки проекта — без сервера** (ВЛ-04): проект сугубо индивидуальный —
   без аккаунтов, публикации документов и шаринга; передача документов —
   PDF/.md/самодостаточный .html. Следствия: fp №7 и №14 отменены
   (статусные заглушки), fp №7б выделен в полноценную карту (v0.3.0),
   fp №12 — клиентский вариант (base64), v1.0.0 = стабильный статический
   релиз (план §1 волна 7), техпаспорт §11, SECURITY §3.1, LICENSE ч.3 п.7.
4. **Прочие решения владельца** (ВЛ-03…ВЛ-11, ЮР-01…ЮР-03 — детали в
   voprosy ред. 2.0): favicon — нейтральная иконка книги (ВЛ-03); LICENSE —
   правообладатель-псевдоним `paprekolyx` без публикации ФИО (ВЛ-05,
   заключение аналитика: ст. 1265 ГК РФ + условия MIT позволяют); контакт —
   Albert23NO@ya.ru без изменений (ВЛ-06); печать — переключатель A4/Letter,
   дефолт Letter (ВЛ-07, ADR-003 ред. 1.1); шрифты — готический/старопечатный
   склад, OFL-кандидаты: Cormorant Unicase/SC, Alegreya, Fira Sans Condensed,
   Ruslan Display (ВЛ-08, ADR-002 ред. 1.1, проверка — АН-03); интерфейс
   только RU, i18n — fp №18 ≥v1.x (ВЛ-09); эталон один (ВЛ-10); ассеты —
   умеренная стилизация, CC0/собственные (ВЛ-11); бесплатно всегда (ЮР-01);
   юрстраницы/РКН не требуются (ЮР-02); памятка Fan Content Policy/SRD 5.1
   (CC-BY-4.0) в справке — fp №10 (ЮР-03).
5. **Рабочий трекер задач** (поручение 3): создан в корне рабочей области
   аналитика — инструмент оперативного управления волнами,
   АН/ВЛ/fp-статусами. В репозиторий НЕ публикуется (регламент §3.5 —
   документы не ссылаются на неопубликованные материалы); публичная истина
   по задачам — `docs/plan/plan-razrabotki.md` §6, синхронизируется каждой
   волной.
6. **Открыт ВЛ-02** (порядок бэклога fp): владелец пришлёт приоритеты
   с комментариями позже — вопрос ждёт минимум 3 волны; до этого действует
   предварительный порядок аналитика (ядро не блокируется).

1. **Переименовать репозиторий**: Settings → General → Repository name →
   `Deigracht` → Rename (`docs/setup/setup-repo-pages.md` шаг 0);
2. загрузить 14 файлов пакета (§2) — веб-интерфейсом или git;
3. коммит(ы) с сообщением: **`0.0.2-draft`** (регламент §4.2);
4. чек-лист приёмки:
   - [ ] репозиторий называется `Deigracht`, старый URL перенаправляется;
   - [ ] все 14 файлов загружены, пути совпадают с §2;
   - [ ] ветка main, репозиторий public;
   - [ ] README открывается на главной без битой разметки (таблицы, дерево);
   - [ ] LICENSE определяется GitHub'ом (MIT-блок части 1);
   - [ ] SECURITY.md виден во вкладке Security;
   - [ ] Pages НЕ включён (Settings → Pages → None);
   - [ ] `treker.md` и другие рабочие файлы аналитика НЕ загружены.
