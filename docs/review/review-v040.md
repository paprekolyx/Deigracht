## 2. Находки

**Ф-01 (средняя).** Несходимость авто-TOC при осцилляции: цикл проходов
ограничен тремя; если добавление цифр номеров само сдвигает границу
страницы рядом с оглавлением, последний проход может показать номера,
измеренные на предыдущей пагинации (отставание на один проход).
Воспроизведение: документ, где оглавление стоит вплотную к `\page` и
ширина строки «…82» против «…» меняет перенос. Место: `assets/js/editor.js`
(цикл рендера), `assets/js/toc.js` (collect). Предложение в рамках
ограничений: честное предупреждение в статус-баре при несходимости +
граничная заметка в техпаспорте §10 (культура честных границ, а не silent
дефект).

**Ф-02 (низкая).** Пустое автооглавление (в документе нет заголовков
выбранного диапазона, напр. `{{toc,auto:2}}` при главах h3) рендерилось
пустой рамкой без объяснения. Место: `assets/js/toc.js` (buildNav).
Предложение: плашка-подсказка с указанием диапазона и способа его уточнить.

**Ф-03 (низкая).** `parseSpec` принимал уровни вне 1–6 (`{{toc,auto:0}}`,
`{{toc,auto:9}}`): диапазон уезжал в пустоту или «все уровни» без ведома
пользователя. Место: `assets/js/toc.js` (parseSpec). Предложение: clamp
1–6 после разворота обратного диапазона.

**Ф-04 (низкая).** В справке демо ручного `{{toc,wide}}` содержит номера
страниц, проставленные рукой; читатель может принять их за результат
автосборки и не понять разницу режимов. Место: `assets/js/help.js`
(demoSrc). Предложение: явное примечание «выше — ручной TOC, номера рукой
(демо синтаксиса); ниже — авто».

**Ф-05 (средняя, отложена решением).** Производительность: авто-TOC даёт
до 3 полных пагинаций разворота за один рендер (обычно 2). На эталоне
178 632 знака DoD «полный перерендер ≤ 2 с» в худшем случае под вопросом;
измерение в среде ревьюера невозможно (нет браузера). Место:
`assets/js/editor.js` (цикл), `assets/js/help.js`. Предложение: замер
властителем на приёмке волны; при превышении DoD — решение об ограничении
числа проходов (2) для документов крупнее `limits.maxDocChars`.

**Ф-06 (наблюдение, не находка).** В экспортированном самодостаточном
.html якоря `#pN` оглавления не кликабельны (обработчик клика живёт в
editor.js). Противоречия нет: экспорт — снапшот для печати/PDF и передачи
(fp №7б, ВЛ-04); навигация по якорям — функция редактора. Действий не
требуется; отметить в справке не нужно (граница очевидна из назначения
экспорта).

**Ф-07 (наблюдение, не находка).** `404.html` не загружает toc.js — на
странице нет конвейера рендера; паритет скриптов соблюдён по назначению
страниц (check-repo §8 считает пары по index/404/help и зелёный).
