чтобы не было юридических ограничений использования».
**Учтено:** переименование всех документов и репозитория (АН-12); проверка
уникальности выполнена (АН-11 закрыта): веб-поиск — единственное совпадение,

`docs/plan/otchet.md` §7. Глубокая товарно-знаковая проверка не требуется
на текущем этапе (проект бесплатный и некоммерческий — ЮР-01); повторная
проверка — при покупке домена, если состоится (R8).

## Блок 2. Продукт и дизайн

**ВЛ-04.** Нужен ли шаринг по ссылке / сервер.
**Ответ (07.10.2026, владелец):** «Нет, проект сугубо индивидуальный,
не планируется ни аккаунтов, ни публикации документов, ни шаринга по
ссылке — достаточно PDF/экспорта файлов».
**Учтено:** fp №7 и №14 отменены (статусные заглушки); fp №7б (экспорт
самодостаточного .html) — основной способ передачи документов, целевая
волна v0.3.0; v1.0.0 = стабильный статический релиз (план §1, волна 7);
техпаспорт §11; SECURITY §3.1; LICENSE ч.3 п.7.

**ВЛ-05.** Публикация ФИО и статуса правообладателя в LICENSE.
**Ответ (07.10.2026, владелец):** «Уточнить, необходимо ли публиковать ФИО
и статус — если есть возможность, то оставить только контакт (почта)».
**Заключение аналитика (07.10.2026):** публикация ФИО/статуса НЕ требуется —
условия MIT допускают любое обозначение правообладателя, включая псевдоним;
законодательство РФ допускает обнародование произведения без указания имени
(ст. 1265 ГК РФ), личность может быть раскрыта позже. **Решение:** в LICENSE
правообладатель — псевдоним `paprekolyx` + контактная почта; ФИО не
публикуется. **Учтено:** LICENSE.md (0.0.2-draft).

**ВЛ-06.** Контакт для связи.
**Ответ (07.10.2026, владелец):** «Оставляем Albert23NO@ya.ru, это моя
основная почта для связи по всем проектам».
**Учтено:** контакт во всех документах без изменений.

**ВЛ-07.** Формат страницы: A4 или Letter.
**Ответ (07.10.2026, владелец):** «Делаем переключатель A4/Letter. PDF эталон
печатался в Letter, так как в А4 оставались белые подвалы внизу страницы».
**Учтено:** ADR-003 ред. 1.1 (otchet §4): переключатель в настройках печати,
дефолт **Letter** (геометрия эталона); задача чистой печати обоих форматов
без белых полос — АН-05; реализация — pdf.js/print.css волны v0.1.0 (fp №4).

**ВЛ-08.** Шрифты книги.
**Ответ (07.10.2026, владелец):** «Нужен стиль готики, похожий на шрифты из
официальных книг ДНД, но доступный без покупки лицензии. Попробуем вариант,
который предложишь ты, при необходимости изменим в одну из волн разработки».
**Учтено:** ADR-002 ред. 1.1 (otchet §4) — предложение аналитика: заголовки —
Cormorant Unicase/SC; текст книги — Alegreya; статблоки/UI — Fira Sans
Condensed; буквицы/готический акцент — Ruslan Display (опционально); все —
OFL с кириллицей. Уточнение аналитика: официальные книги D&D используют
старопечатную антикву и «траяноподобные» капители, а не фрактуру; набор
кандидатов воспроизводит этот характер и доступен бесплатно. Проверка
на эталоне — АН-03; замена возможна до v0.2.0 без переделок (токены темы).

**ВЛ-09.** Язык интерфейса.
**Ответ (07.10.2026, владелец):** «Только русский, иностранные языки не
раньше v1.x по отдельному запросу (можно добавить в fp одним из последних
пунктов)».
**Учтено:** fp №18 (i18n) — последняя карта бэклога, целевая ≥v1.x.
